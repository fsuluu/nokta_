# Audit Report — Search Feature Proposal

## Screen

IdeaListScreen

## Severity

Suggestion

## Problem

Kullanıcı çok fazla fikir kartı olduğunda belirli bir kartı hızlı bulmakta zorlanabilir.

## Expected Behavior

Liste ekranında temel bir arama alanı bulunabilir.

## Suggested Fix

- Basit bir search input eklenebilir
- Kart filtreleme yapılabilir
- Gerçek zamanlı arama desteği eklenebilir

## Result

Bu özellik denenmiş ancak mevcut ödev kapsamı için fazla detaylı bulunduğu için rollback uygulanmıştır.
